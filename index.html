clip-farm

A personal tool for publishing short-form clips to YouTube channels I own.

What it does

clip-farm runs on my own computer. It cuts short vertical clips from long videos, adds captions, and uploads them as YouTube Shorts to my own channels through the YouTube Data API. It also reads view counts for those uploads so I can see which clips do well.

Who it's for

Only me. It is not a public service, there is no sign-up, and it does not access anyone else's account.
